# UmlTool

日本語 | [English](README.en.md)

Visio のように要素を自由配置・自由配線できる WYSIWYG の UML 作図ツール。
シーケンス図・アクティビティ図・マインドマップに対応。サーバーレスの Electron デスクトップアプリ。

- エンジン: [AntV X6](https://github.com/antvis/X6) v3 + Electron + TypeScript (electron-vite)
- テキスト（PlantUML サブセット）からの**初期生成は一方向**（生成後は GUI で自由に調整）
- プロジェクト保存は `.umlproj`（JSON エンベロープ + X6 モデル）
- 画像書き出し: PNG / JPEG / WebP（解像度を 72〜600dpi から選択。1 辺 8192px を超える場合は自動で下げます）
- 未保存の変更があるまま新規・開く・図種別切替・終了をすると、**保存する / 保存しない / キャンセル**の確認が出る

## 開発

```bash
npm install
npm run dev        # 開発起動
npm run typecheck  # 型チェック
npm test           # ユニットテスト (Vitest)
npm run build      # プロダクションビルド (out/)
npm start          # ビルド済みをプレビュー起動
```

### ヘッドレス自己診断

```powershell
$env:UMLTOOL_DIAG='1'; npx electron-vite preview
```

図の生成・3 形式書き出し・保存⇄読込ラウンドトリップ・編集挙動を検証し、
`diag-output.png`（アクティビティ図）/ `diag-output-seq.png`（シーケンス図）/
`diag-output-mindmap.png`（マインドマップ）/ `diag-output-ui.png`・`diag-output-panel.png`（画面）を出力します。

## 操作方法

| 操作 | 方法 |
|---|---|
| スクロール | マウスホイール（スクロールバーも可） |
| ズーム | Ctrl + ホイール（カーソル位置基準）、ツールバー −/100%/＋/全体 |
| パン | 空白部を左ドラッグ、または中ボタンドラッグ |
| 矩形選択 | Shift + 左ドラッグ |
| 選択に追加 / 解除 | Ctrl + クリック |
| 複数まとめて移動 | 複数選択した状態で、いずれかをドラッグ（選択を囲む枠はクリックを遮らないので、枠の内側にある未選択のノードもそのまま選べます） |
| undo / redo | Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） |
| コピー / 切り取り / 貼り付け | Ctrl+C / Ctrl+X / Ctrl+V（貼り付けは少しずらして配置） |
| すべて選択 | Ctrl+A |
| まとめて選択 | **Shift + ←→↑↓**。選択したものより「その向きにある」ノードを一気に選択へ追加（右パネル「まとめて選択」の ↑↓←→ ボタンでも可）。**向きは続けて押せます**（下→右で「下にあるもの」と「右にあるもの」の両方が入る）。基準は最初に選んだ要素のままで、選択し直すと基準も取り直します |
| 選択を動かす | **Ctrl + ←→↑↓**（8px、Shift 併用で 40px）。ドラッグでも可 |
| 整列 | 複数選択 → 右パネル「整列」で 左 / 左右中央 / 右 / 上 / 上下中央 / 下 に揃える |
| 削除 | Delete / Backspace またはツールバー 🗑 |
| ショートカット一覧 | **?**（または F1、ツールバーの「?」）。図の上に半透明で重なり、Esc / ? / クリックで閉じます。表示中のキーはその図種別のものに切り替わります |
| 部品の追加 | 左ペイン「部品」タブのアイコンをクリック |
| テキスト（付属） | 部品パレットの「テキスト」。選択中のライフラインに付属（破線で結び、移動に追従、シーケンス図）。内容はダブルクリック、フォントサイズ・太字・色は右パネル、ハンドルで横幅変更（自動折り返し） |
| ノート（付箋） | 部品パレットの「ノート」。左上折りの付箋で、どこにでも自由配置（両図種）。編集・スタイルはテキストと同様 |
| プロパティ編集 | 要素を選択 → 右パネルで名前・ラベル・種別を編集 |
| ラベル直接編集 | ノードやメッセージを**ダブルクリック**してその場で編集 |
| 外観の変更 | 要素を選択 → 右パネル「外観」で背景色・線の色・フォントサイズ・フォント・太字・文字色を変更 |

ラベルはノードに合わせて自動で折り返され、ノード幅もラベルに合わせて自動調整されます（上限あり）。フォントサイズやフォントを変えると、その実寸に合わせて自動調整もやり直されます。

### 外観（色・フォント）

- 要素を選択すると右パネルに「**外観**」欄が出ます。図形が持てる項目だけが表示されます（例: 開始・終了・フォークは背景色のみ、合流は背景色と線の色のみ）
- **カラーピッカーはプリセットと自由入力の併用**です。並んでいる色見本をクリックすれば即適用、左の色ボックスからは任意の色を選べます
- 対象: ライフライン / 活性化バー / フラグメント / アクション / 分岐 / 合流 / 開始 / 終了 / フォーク / ジョイン / レーン / フレーム / テキスト / ノート / 中心トピック / トピック
- **矢印も同じ「外観」欄で変えられます**。線の色は矢じりまで一緒に変わり、フォントサイズ・フォント・太字・文字色は線に乗るラベルに効きます（対象: メッセージ / フロー / マインドマップの枝）。文字を書き換えたり、メッセージ種別を変えたりしてもスタイルは残ります

### シーケンス図

- **メッセージの作成**: ライフラインの生存線（縦破線）からドラッグして相手のライフラインへ。
  または部品パレットの「メッセージ」（2 要素を選択→選択順に接続。1 要素なら最寄りへ、未選択なら先頭 2 本）
- **外部メッセージ（ゲート）**: 部品パレットの「外部から」（PlantUML の `[-> A`）/「外部へ」（`A ->]`）。選択中のライフライン（未選択なら一番左）に付き、反対側は図の外の自由な点になります。上下ドラッグでは点側も追従して水平を保ちます
- **メッセージの上下移動**: メッセージを選択し、中央のハンドルを上下ドラッグ（常に水平を維持）
- **繋ぎ替え**: 選択して端点ハンドルを別のライフラインへドラッグ
- **種別**: 同期（実線・塗り矢印）/ 非同期（実線・開矢印）/ 戻り（破線・開矢印）/ 自己（ループ）— 右パネルで切替
- **活性化バー（実行仕様）**: 部品パレットの「活性化バー」。ライフラインの中心線上に拘束され、上下移動・縦横リサイズ可。バーが重なると、内側のものが astah* のように 1 段ずつ右へずれて積み重なります（ずれ幅はバー幅の半分）
- **複合フラグメント**: 部品パレットの「フラグメント」。種別（alt / opt / loop / break / par / seq / strict / critical）と条件は右パネル、条件はダブルクリックでも編集可。枠線ドラッグで移動、選択してリサイズ。alt / par は右パネル「＋区切り線を追加」で破線の区切りを追加（上下ドラッグで移動、Delete で削除）

### アクティビティ図

- ツールバーの図種別セレクトで「アクティビティ図」に切替
- **フローの作成**: ノードにホバーすると出る接続ポート（上下左右の丸）からドラッグ。
  または部品パレットの「フロー」（2 ノードを選択→選択順に接続。1 ノードなら最寄りへ）
- フローは直交ルーティング（manhattan）。選択して経由点を追加・調整可能
- ガード条件はフローを選択して右パネルで編集
- **分岐と合流は別ノード**: 分岐（デシジョン）は条件ラベル付きの菱形、合流（マージ）は小さな空の菱形（部品パレットの「合流」）
- **分岐の図形**: ツールバーの「分岐:」で **菱形** / **6 角形**（PlantUML 風の横長）を選べます。図全体の設定で、既存の分岐すべてと以降に追加する分岐に適用され、プロジェクトファイルに保存されます。合流は分岐と見分けが付くよう菱形のままです。切り替えるとレイアウトが崩れることがあります
- **枝は重ならない**: 分岐からは下・右・左へ、合流へは上・右・左から、枝が別々の辺に自動で振り分けられます（相手ノードの位置に応じて決まり、移動すると付け直されます）。枝が 4 本以上あって辺が足りないときだけ重なります
- **接続先は上辺中央**: 送信元が送信先より上にあるフローは、送信先の**上辺中央**に接続されます（上から下へ読める配線になります）。合流と分岐は上記の枝の振り分けが優先されます。**端点をドラッグで繋ぎ替えると、以降その端点は自動調整されません**（どのノードでも同じ）
- **付けたい辺を指定できる**: フローを選択すると右パネルに「**接続する辺**」が出ます。「出口（元のノード）」「入口（先のノード）」をそれぞれ **自動 / 上 / 右 / 下 / 左** から選べます。分岐・合流のように小さくてポートが密集するノードでも確実に辺を決められ、「自動」でいつでも元の割り当てに戻せます
- **ドラッグでも狙える**: フローを繋ぐとき、ポートの丸を正確に掴めなくても、**離した位置に近い辺**へ接続されます（ノードの外側半分で離したとき。中央付近で離した場合は従来どおり自動で辺が選ばれます）。手で決めた辺は自動割り当ての対象外になるだけでなく、**その辺は他の枝も避ける**ので、重なりません
- **スイムレーン**は選択するとハンドルが出て幅・高さを変更可能。画面いっぱいに広がっても誤操作しないよう、**掴めるのはヘッダ帯と枠線だけ**で、レーンの内側はクリックが通ります（中のノードの選択や範囲選択がそのまま行えます）
- **ノードのリサイズ**: アクション / 分岐 / 合流 / 開始 / 終了 / フォーク / ジョインは選択するとハンドルが出て、右パネルの「幅」「高さ」でも変更可能（開始・終了は真円を保つよう縦横比固定）。**リサイズしてもノードの中心は動きません**（掴んだ辺の反対側も同じだけ広がるので、上下のノードと中心が揃ったままになり、フローが斜めになりません）。アクションと分岐は通常ラベルに合わせて自動リサイズされるが、手動リサイズするとそのサイズが優先される。右パネルの「サイズを自動に戻す」で元の挙動に戻せる
- **フレーム（コンテナ）**: 部品パレットの「フレーム」。左上のヘッダタブ付きの透過枠で、中のノードはそのまま操作可能。枠線かヘッダをドラッグで移動、選択してリサイズ、ヘッダは右パネル/ダブルクリックで編集（タブ幅はテキストに追従）
- **中心が自動で揃う**: ノードをドラッグして離したとき、フローで繋がっている相手との中心のずれが **8px 以内**なら、ぴたりと揃えます。数 px のずれで縦（横）のフローが斜めに見えるのを防ぐためで、それより大きくずらしたときは意図した配置とみなしてそのままです（複数まとめて動かしているときは相対位置を崩さないよう働きません）
- **既にずれてしまったものは整列で直せます**: 縦に並んだノードを複数選択 → 右パネル「整列」→「左右中央」で中心が揃います
- **空きを作る**: 新しいノードを差し込む場所を空けたいときは、基準にするノードを選んで **Shift+↓**（その下にあるノードを一括選択）→ そのままドラッグか **Ctrl+↓** で下げます。続けて **Shift+→** のように別の向きを足すこともできます（基準は最初に選んだノードのまま）。掴むのは「基準の下端より下から始まっているもの」だけなので、横に離れたノードも一緒に下がり、基準と縦に重なっているノードは動きません
- 新規ノードは**表示中の画面の中央**に追加される（連続追加時は少しずつずれる）

### マインドマップ

- ツールバーの図種別セレクトで「マインドマップ」に切替
- **2 つの表示**: ツールバーの「表示:」で切り替えます。どちらも同じ木を描き直すだけで、内容は変わりません
  - **マインドマップ**: 中心トピックから左右へ放射状に展開（第 1 階層の子は部分木の大きさが釣り合うよう左右へ振り分け、孫以降は親と同じ側へ伸びます）
  - **ツリー**: 1 トピック 1 行の縦インデント（エクスプローラのツリー風）。枝は必ず**親の下端から真下に降り、直角に曲がって子の左端へ入ります**（トピックを手で動かしても L 字は崩れません）
- **配置は自動整列と自由配置の併用**: 自動配置が走るのは**テキストから生成したとき**と**「整列」ボタン / 表示の切替**のときだけです。それ以外はどのトピックも自由にドラッグでき、動かした位置はそのまま保たれます
- **キーボードだけで操作できます**。割り当ては **?** キーの一覧（図の上に半透明で重なる）と、部品タブの下の常設ヘルプで確認できます

| キー | 動作 |
|---|---|
| ↑ / ↓ | 兄弟トピックへ移動（ツリー表示では前後の行へ）。兄弟が尽きたら同じ深さ・同じ側の隣へ続きます |
| ← / → | 親 / 子トピックへ移動。マップ表示では**枝の向きに追従**します（右へ伸びた枝では → が子、左へ伸びた枝では ← が子）。ツリー表示は ← が親・→ が子で固定 |
| Home | ルートへ移動 |
| Tab | 子トピックを追加 |
| Enter | 兄弟トピックを追加 |
| F2 | 名前を編集 |
| Space | 折りたたみ / 展開 |
| Ctrl + X | トピックを**子ごと切り取る**（親との枝を外す。ノードは図に残ります） |
| Ctrl + C | トピックを**子ごとコピー**する |
| Ctrl + V | 切り取り / コピーしたものを**選択トピックの子として**貼り付ける |
| Esc | 切り取り / コピーを取り消す（切り取りは元の親へ繋ぎ直します） |
| Ctrl + ↑↓←→ | トピック自体を動かす（8px。Shift も押すと 40px） |
| 1 〜 6 | 配色を変える（ブルー / グリーン / イエロー / レッド / パープル / グレー） |
| 0 | 配色を既定（深さの色）に戻す |
| B | 太字 |
| C | **コード表示**の切替（等幅・左揃え・インデント保持。C++ などの引用に） |
| + / - | 文字サイズを増減（ノード幅も測り直されます） |
| Delete | 削除 |

- 移動・装飾は**選択中のトピック**に対して働きます。何も選んでいない状態で矢印を押すとルートが選ばれます。装飾は複数選択にまとめて当たります
- 追加系（Tab / Enter）は追加直後にそのまま名前を入力できます。同じ操作は部品パレットの「子トピック」「兄弟トピック」「折りたたみ」からも行えます
- **枝でつなぐ（親子の作成）**: 枝はトピックの親子関係そのものです。離れたところに作ったトピックを既存の木へ繋ぐときに使います
  - **ドラッグ**: トピックの接続ポート（上下左右の丸）から相手のトピックへドラッグします。**ドラッグを始めた側が親**、離した側が子です
  - **部品パレットの「枝でつなぐ」**: **親にするトピック → 子にするトピック**の順に選んでから押します。1 つだけ選んだときは、近くにある「まだ親のいないトピック」が子になります
  - 木を壊す繋ぎ方は受け付けません（既に親がいるトピックを子にする、輪になる向きに繋ぐ）。親を変えたいときは切り取り＆貼り付け（Ctrl+X → Ctrl+V）を使ってください
  - 既にある枝は、選択して端点ハンドルをドラッグしても繋ぎ替えられます
- **トピックの付け替え（切り取り＆貼り付け）**: Ctrl+X → 貼り付け先のトピックを選んで Ctrl+V で、サブツリーごと別の親の下へ移せます。切り取りは親との枝を外すだけなので、貼り付けを忘れてもトピックは図に残ります（破線・薄い表示が切り取り中の印。Esc で元の親へ戻ります）。自分自身や自分の子孫の下へは貼り付けられません
  - **親と自分の間にトピックを挟む**には、自分を Ctrl+X → 親を選んで Tab で新しいトピックを作る → Ctrl+V
  - Ctrl+C で同じ形のサブツリーを複製できます（配色・折りたたみ状態もそのまま）
- **折りたたみ**: 隠れるのは子孫だけで、位置は動きません。詰め直したいときは「整列」を押します
- ルート（親を持たないトピック）は複数あっても構いません。整列すると 2 本目以降は下へ積まれます
- 色は深さに応じて自動で決まりますが、右パネルの「外観」でいつでも変えられます（整列しても上書きされません）
- **コードの引用**: トピックを選んで **C**（または右パネルの「コード表示」/ 部品パレットの「コード」）を押すと、同じトピックのまま**等幅・左揃え・折り返し無し**の表示に切り替わります。もう一度押すと通常のトピックに戻ります
  - 行頭のインデントはそのまま残ります。タブは 4 桁ごとの空白に展開し、行末の空白と前後の空行は落とします
  - 編集（ダブルクリック / F2）中は **Enter が改行、Ctrl+Enter で確定**、Tab で空白 4 つ。右パネルの「コード」欄でも同じように編集できます
  - ノードは一番長い行と行数に合わせて広がります。色・文字サイズ・太字は通常のトピックと同じ操作で変えられます

## テキスト生成（PlantUML サブセット）

### シーケンス図

```
participant ユーザー
participant "Web サーバー" as サーバー
actor 管理者
ユーザー -> サーバー : 同期メッセージ
ユーザー ->> サーバー : 非同期メッセージ
activate サーバー
サーバー --> ユーザー : 戻り
サーバー -> サーバー : 自己メッセージ
deactivate サーバー
alt 認証OK
  サーバー --> ユーザー : 成功
else 認証NG
  サーバー --> ユーザー : 失敗
end
note right of サーバー : ライフラインに付属するテキスト
note over ユーザー, サーバー : 二者にまたがる付箋
note left of ユーザー
複数行の
本文も書けます
end note
[-> サーバー : 図の外から来るメッセージ
サーバー ->] : 図の外へ出るメッセージ
autoactivate on
ユーザー -> サーバー : 呼び出しでバーが開く
サーバー --> ユーザー : 戻りでバーが閉じる
```

- **表示名とエイリアス**: `participant "表示名" as エイリアス`。以降はエイリアスで参照します。
- **活性化バー**: `activate 参加者` … `deactivate 参加者`。`deactivate` を省略すると末尾で自動的に閉じます。
- **バーの自動開閉**: `autoactivate on` 以降は、呼び出し（`->` / `->>`）が宛先のバーを開き、戻り（`-->`）が送信側のバーを閉じます。`autoactivate off` で以降のメッセージには適用されなくなります（開いたままのバーは末尾で閉じます）。明示の `activate` / `deactivate` と混在させても互いに影響しません。
- **複合フラグメント**: `alt` / `opt` / `loop` / `break` / `par` / `seq` / `strict` / `critical`（`end` で閉じる、ネスト可）。
  `else` による破線の区切りは `alt` / `par` 内で使えます（各オペランドの条件は生成後、右パネルでも個別に編集できます）。
- **注釈**: 2 種類の図形に振り分けられます。
  - `note left of 参加者` / `note right of 参加者` → **テキスト**（そのライフラインに付属し、破線で結ばれ、移動に追従）
  - `note over 参加者` / `note over 参加者, 参加者` → **ノート**（自由配置の付箋。複数指定するとその範囲を覆う幅になる）

  どちらも `:` 以降に本文を書くか、`:` を省いて次行から `end note` までを複数行の本文にできます。注釈はその直前のメッセージの下に置かれ、続くメッセージはその分だけ下にずれます。
- **図の外とのやりとり（ゲート）**: `[-> 参加者`（外から）と `参加者 ->]`（外へ）。矢印の種別（`->` / `->>` / `-->`）はそのまま使えます。ゲート側の端点は参加者を持たない自由な点になり、外から来るものは相手の左、外へ出るものは相手の右に伸びます。`[->]` のように両端を外にすることはできません。

### アクティビティ図

```
|受付|            ← スイムレーン（任意）
start
:注文を受け付ける;
if (在庫あり?) then (yes)
  :商品を引き当てる;
else (no)
  :取り寄せを手配する;
endif
fork
  :請求書を発行する;
fork again
  :商品を発送する;
end fork
stop
```

コメントは行頭 `'` `#` `//`。`@startuml` / `@enduml` / `title` は無視されます。

### マインドマップ

行頭 `*` の数で階層を表す **PlantUML mindmap 互換の書き方**と、**インデント**の書き方の
どちらでも書けます（同じテキスト内での混在はエラー）。

```
* Webサイト刷新
** 企画
*** 競合調査
** 開発
```

```
Webサイト刷新
  企画
    競合調査
  開発
```

- マーカーは `*` `+` `-` のいずれも使えますが、**深さを表すだけ**です（PlantUML の `-` による左右指定は、本ツールが左右を自動で振り分けるため無視されます）
- インデントの 1 段の幅は、最初に字下げされた行の幅で決まります（タブは半角 4 文字換算）。その倍数になっていない行はエラー
- ラベル中の `\n` は改行になります。`*[#色]` のような装飾は読み飛ばします
- 階層を 2 段以上飛ばすとエラー。深さ 0 の行が複数あれば、その数だけルートができます
- コメントは行頭 `'` `//`。`@startmindmap` / `@endmindmap` / `title` は無視されます

## ファイル形式 `.umlproj`

```json
{
  "format": "umltool-project",
  "version": 2,
  "diagramType": "sequence",
  "settings": { "decisionShape": "diamond", "mindmapLayout": "map" },
  "graph": { "cells": [] }
}
```

`diagramType` は `sequence` / `activity` / `mindmap`。`settings` は図全体の設定で、
古いファイルに無い項目は既定値になります。

version 1（旧 maxGraph 実装の XML 形式）は読み込めません（明示エラー）。
